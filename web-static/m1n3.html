How M1N3 Works

🎯 Verification Process

1. Bitcoin block headers are registered on Sui blockchain as source of truth

2. Full nodes coordinate to divide block fields for verification

3. Dynamic granularity adjusts based on participating nodes (byte or bit level)

4. Nodes submit field data which is verified on-chain using SHA-256

5. Successful verifications earn M1N3 tokens (subsidy × 1000)

💰 Reward Structure

Total Reward: Original Block Subsidy × 1,000

Block Verification: 50% (currently active)

Merkle Root: 50% (disabled - reserved for future)

Example: Genesis Block (50 BTC) = 50,000 M1N3 tokens (25,000 for block verification)

Dynamic Granularity:

• 1-100 nodes: Fields divided by byte

• 100+ nodes: Fields divided by bit (8× more granular)

• This ensures fair participation opportunities as network grows

Getting Started

Run M1N3 Node

python run_p2pool.py \
    --m1n3-enable \
    --m1n3-package-id 0xYOUR_PACKAGE_ID \
    --m1n3-registry-id 0xYOUR_REGISTRY_ID \
    --m1n3-treasury-id 0xYOUR_TREASURY_ID \
    --m1n3-start-height 0 \
    --m1n3-auto-verify

Benefits of Participating:

  • Earn M1N3 tokens for verifying Bitcoin blockchain data
  • Contribute to decentralized Bitcoin verification infrastructure
  • No mining hardware required - just verify existing blocks
  • Rewards proportional to original Bitcoin block subsidies
